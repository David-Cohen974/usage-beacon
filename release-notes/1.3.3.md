# UsageBeacon 1.3.3

- Claude usage refreshes wait for readable data and reuse the connected session to discover the usage endpoint, reducing intermittent loading errors.
- Provider edits are saved when quitting, including changes made immediately before closing the app.
- Canceled refreshes stop cleanly without publishing late results or retrying canceled requests.
- Claude and Cursor personal connections now pass server retry delays to the refresh scheduler. Cursor avoids opening its dashboard as a fallback when rate limited.
- Provider settings have aligned status badges, shorter labels, and a wider adaptive usage layout.
- Widgets keep their title on one line and show failed sources instead of hiding errors behind cached totals.
- Turning launch at login off no longer attempts to unregister an unavailable service.
